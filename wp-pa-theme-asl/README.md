# WP Digital Italia - ASL (child theme)

Child theme di `wp-pa-theme` (`Template: wp-pa-theme`) per le Aziende Sanitarie Locali. Non ridefinisce colori né font: usa il profilo grafico, le opzioni tema e i template del parent.

- `style.css`: intestazione del tema.
- `functions.php`: carica `assets/css/asl.css` dopo gli stili del parent.
- `assets/css/asl.css`: personalizzazioni specifiche ASL (loghi, spaziature).

Per sovrascrivere un template del parent, copiarlo qui con lo stesso percorso. Le opzioni (boxed/full, slider news, box contatti) sono in Aspetto → Personalizza → *Layout e Home*.
