# WP Digital Italia - ASL (child theme)

Child theme di `wp-pa-theme`. Non ridefinisce colori né font: usa il profilo del parent.
Le opzioni (boxed/full, slider news) si trovano in Personalizza → *Layout e Home*.

- `style.css`: intestazione del tema (`Template: wp-pa-theme`).
- `functions.php`: carica `assets/css/asl.css` dopo gli stili del parent.
- `assets/css/asl.css`: personalizzazioni ASL (loghi, spaziature).
- Per sovrascrivere un template del parent, copiarlo qui con lo stesso percorso.
